# ThroneMatch-GOT

**ThroneMatch-GOT** is a character matching system for the *Game of Thrones* series. Using machine learning algorithms, it matches characters based on their traits and features, providing users with accurate recommendations for similar characters. The application is designed with an interactive interface to enhance user experience.

## Features
- **Character Matching**: Match characters from *Game of Thrones* based on various traits and features.
- **Interactive Interface**: Built with Streamlit for an easy-to-use, visually appealing interface.
- **User-Friendly**: Displayed data includes character names and images for better visual comparison.
- **Personalized Recommendations**: Suggest similar characters based on user selection.

## Technologies Used
- **Python**: The primary language used for the project.
- **Streamlit**: A framework for building the app’s interactive interface.
- **Machine Learning**: For analyzing and matching characters based on attributes.
- **Pandas**: Data manipulation and analysis.
- **NumPy**: For handling numerical data in the backend.
  
## APIs Used
- **ThronesAPI**: Provides data about *Game of Thrones* characters, including their names, images, and traits, which are used for character matching.
